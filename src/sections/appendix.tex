\section{Glossary}

\begin{description}[style=nextline]
\item[Ante handler] Code that runs before a transaction's messages execute:
  signature verification, nonce checks, fee deduction, and on this chain the
  compliance and circuit-breaker checks. Its ordering is security-critical.
\item[Base fee] The EIP-1559 per-gas price set by the protocol from recent
  block fullness. Burned on Konstellation.
\item[Bonded] \kash{} delegated to a validator and subject to the unbonding
  period and slashing. The input to the issuance curve.
\item[Circuit breaker] An on-chain control that disables specific message
  types without halting the chain.
\item[Cosmovisor] The process manager that swaps node binaries at a
  governance-set upgrade height.
\item[EntryPoint] The ERC-4337 singleton contract through which user
  operations from smart accounts are executed.
\item[Genesis transaction (gentx)] A pre-signed validator-creation transaction
  merged into the genesis file, which is how the launch validators are bonded
  at block zero.
\item[Preinstall] A contract placed in the genesis state at a fixed address
  without running its constructor.
\item[Sentry] A public-facing node that shields a validator, which has no
  public address of its own.
\item[Tip] The EIP-1559 priority fee, paid to validators and delegators.
\item[Tombstone] Permanent removal of a validator from the active set after
  double-signing.
\end{description}
