\begin{abstract}
Konstellation is a sovereign Layer~1 blockchain built on the Cosmos~SDK with an
EVM execution layer provided by \code{cosmos/evm}. It is EVM-compatible at the
level developers and wallets expect: Solidity contracts, Ethereum JSON-RPC,
MetaMask and Rabby support, and a Blockscout explorer. Its native asset is
\kash{}. This document describes the architecture and the engineering posture
behind it (consume upstream, never fork; ship the smallest possible amount of
custom consensus code), the economics of \kash{} (a stake-based issuance curve
paired with an EIP-1559 base-fee burn), the validator set as it will actually be
at launch and how it is intended to open, the deliberate absence of a bridge on
day one, the chain-wide compliance module and the trade-offs it carries, native
account-abstraction support, and the security and launch process. It is
written to be cited by version: economic parameters change only with a new
release of this document.
\end{abstract}
